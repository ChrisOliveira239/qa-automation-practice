# QA Automation Learning Journey 🚀

Este repositório contém meus estudos e projetos práticos focados em *Engenharia de Qualidade e Automação de Testes*. Como desenvolvedor Fullstack, busco aplicar as melhores práticas de desenvolvimento para garantir a resiliência e a qualidade de softwares escaláveis.

## 🛠 Tecnologias & Ferramentas
- *Web Automation:* Playwright (TypeScript)
- *API Testing:* Codeception (PHP) & Postman
- *Language:* TypeScript, PHP, SQL
- *CI/CD:* GitHub Actions

## 🧪 Projetos Incluídos

### 1. Automação E2E com Playwright
Localizado em /playwright-e2e. 
- *Cenários:* Login, Fluxo de Checkout e validação de componentes dinâmicos.
- *Destaque:* Uso de Locators avançados e Page Object Model (POM).

### 2. Testes de API com Codeception
Localizado em /codeception-api.
- *Cenários:* Validação de Endpoints REST, status codes e contratos JSON.
- *Contexto:* Testes focados em aplicações estruturadas em PHP/Laravel.
